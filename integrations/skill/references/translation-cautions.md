# Sens et construction / Meaning and construction

- Une étiquette de recherche n’autorise pas tous les sens du mot français ou anglais. Lire définition, valence, registre et validation. / A lookup label does not license all senses: read definition, valency, register and status.
- Distinguer admiration et menace, colère et ivresse, crédulité et folie, erreur et mensonge. / Distinguish admiration from threat, anger from intoxication, gullibility from insanity, error from deception.
- Une insulte culturelle ne crée pas de groupe social dans la langue. Les sens sans équivalent établi restent incertains. / Cultural abuse does not create native social groups; unestablished equivalents remain uncertain.
- Pour la technologie : `korthir` fréquence physique ; `klavir` clavier musical ; `paed` nappe sonore ; `kaeneth-dolgik` pad physique ; `saevron` taille anatomique. / Technical senses distinguish frequency, keyboard, pad sound, physical pad and anatomical waist.
- Les métaphores ne changent pas les définitions physiques. Les pronoms possessifs requièrent leurs antécédents. Compléter les emplacements de `schema_a_completer`. / Metaphors preserve physical definitions; possessives need antecedents and template slots must be filled.
- Préserver la portée de *only*, la différence entre *unforgotten* et *unforgettable*, et les acteurs de chaque proposition. / Preserve restrictive scope, memory distinctions and clause participants.
- SVO ; pluriel puis cas ; adjectifs postposés invariables ; valence obligatoire ; négation verbale `nu`, quantification nominale `nul`, intensification adjectivale `sha`. / Apply these grammatical constraints before delivery.
