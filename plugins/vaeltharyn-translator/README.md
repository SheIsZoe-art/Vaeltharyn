# Source du plugin 0.4.0

Ce dossier expose le manifeste, les instructions et le script de recherche pour leur lecture et leur revue dans GitHub. La copie volumineuse du corpus est distribuée dans le [ZIP autonome](../../distributions/vaeltharyn-translator-0.4.0.zip), afin de ne pas dupliquer les grands CSV dans l’arborescence du dépôt.

Pour installer, suivre le [guide](../../INSTALLATION.md) et utiliser le paquet complet. `python scripts/installer_plugin.py`, depuis la racine du dépôt, prépare un dossier de plugin complet et son catalogue local sous `dist/`. Le présent dossier de consultation ne constitue pas à lui seul une installation autonome.

Une modification de ces sources demande de reconstruire un paquet avec sa copie du corpus et de vérifier ses références avant de le distribuer. Modifier ce dossier ne met à jour ni le ZIP versionné ni le plugin personnel publié.
