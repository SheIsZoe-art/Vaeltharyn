# English edition: review status

Corpus 1.5.0 contains 65,041 aligned French and English lexical records with stable IDs. English headwords are lookup labels bounded by full definitions. Bulk definitions have not all been individually reviewed; compare retained French source fields when uncertain. Translation does not validate automatically allocated Vaeltharyn proposals.

The [historical translation report](../../../archives/reports/en/translation-1.2.0.md) documents methods and the earlier 65,007-entry scope. Its counts are historical. Current contextual records include English notes and checked sense formulations, with their own approval caveats.

Current data paths and counts are in [corpus.json](../../../corpus.json). Use [indexed lookup](../integration/lookup.md), and retain [source attribution](sources-and-licenses.md).
