# Translating with Vaeltharyn

1. Read versions and paths in [corpus.json](../../../corpus.json), then [grammar](../reference/grammar.md) and [conjugation](../reference/conjugation.md) for nontrivial translation.
2. Batch words and expressions. Start with exact matching and broaden only when needed. Do not load the large CSVs or historical volumes into context.
3. Read definitions, valency, register, status, notes and assumptions. An alias does not establish equivalence outside its context. Counterexamples document errors, not translation models.
4. Build the sentence using the rules; back-check agents, targets, tense, negation and imagery. Fill every `schema_a_completer` slot. Flag neologisms and senses without an established equivalent.
5. Follow the requested language and format, including song sections and repetitions. Put French and English beneath each line only when requested.

Use [idioms](../expressions.md) for expressive language and nuances, and [sound, body and imagery](../expressions.md) for technical terms and metaphors. Sources and caveats remain available in indexed distributions.
