# Découvrir le Vaeltharyn

Le Vaeltharyn est une langue construite par **SheIsZoe** pour des chants profonds, mystiques, à évocation nordique et celtique. Ce n’est pas une langue historique. Son nom propre indivisible se prononce /ˈvæːl.θa.ryn/.

La grammaire productive, les règles de conjugaison et les formations de mots permettent d’écrire au-delà des lemmes attestés, en distinguant les propositions des formes approuvées. Un dictionnaire reste évolutif ; son volume ne prouve pas la qualité de chaque entrée.

Utiliser [le guide français](README.md) pour naviguer, [la recherche](integration/lookup.md) pour les fiches actuelles et [la grammaire](reference/grammar.md) pour construire les phrases. Les éditions historiques sont rangées dans les archives ; elles ne remplacent pas la recherche courante.
