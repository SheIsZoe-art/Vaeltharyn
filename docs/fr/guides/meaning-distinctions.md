# Exemples et distinctions de sens

Retour : [00_Accueil](../start.md). Exemples écrits de l’extension 1.1.0 ; aucune validation audio. Ces phrases ne constituent pas des affirmations factuelles ou des actions exécutées.

| Vaeltharyn | Français | Commentaire |
|---|---|---|
| Mi vaerem en maelvel ti-or. | Je te donne le pain. | Objet direct puis bénéficiaire au datif. |
| Mi maelvelem en pelvar. | Je mange la pomme. | Verbe hérité maelvelar ; nouvel objet pelvar. |
| Se vathune en vath. | Il/elle boit l’eau. | vathunar → vathune. |
| Mi mirem en naelmir. | Je vois l’écran. | Écran informatique, pas écran au sens de protection. |
| En thaemnyr vele thiriv. | Le silence est temporaire. | Silence acoustique ; adjectif invariable. |
| En thaelraun vele naelv. | Le refrain est mémorable. | Nom musical ; copule velar. |
| Min thaerom kois. | Nous chantons ensemble. | Accord verbal à la première personne du pluriel. |
| Mi thaemnaelem en thael. | J’enregistre le chant. | thaemnaelar, transitif. |
| Mi thaemvaerem en thaemnael. | Je mixe l’enregistrement sonore. | Action et objet définis dans le même domaine. |
| Mi naelgraelem en naelneli. | Je sauvegarde les données numériques. | naelneli est un nom collectif au singulier lexical. |
| Mi nu naeldhelem en thaemnael. | Je ne télécharge pas l’enregistrement sonore. | Négation nu ; phrase illustrative, aucune action effectuée. |
| Ti sendles en vaeril ma ? | Apprends-tu la langue ? | Interrogation finale ; sendlar → sendles. |

| Mi ravaermarem en naelvel. | J’ai acheté le livre. | ra- + vaermar + em. |

| En maelnayrun mi-en vele vaethv. | Mon conjoint ou ma conjointe est courageux ou courageuse. | Possessif postposé ; adjectif sans accord. |
| Mi thaemsaerem en varnelven. | Je salue le voisin ou la voisine. | Action dirigée vers une personne. |
| Mi maerunem en lyrenraun ti-en. | Je respecte ta limite personnelle. | Verbe transitif ; possessif postposé. |
| En saelhael vele haevvaer. | L’empathie est utile. | saelhael n’est pas la bénédiction saelhaer. |
| En naelkaen vele naiv. | Le programme informatique est nouveau. | naelkaen n’est pas naelkaer, la concentration. |

| En vaurkor vele haervenun. | L’or est lourd. | Or métal, distinct de la monnaie. |

## Pièges de traduction

- **Langue** : `vaeril` système linguistique ; `lyth` organe.
- **Argent** : `lymkor` métal ; `vaermar` monnaie ; `vaervar` prix ; `vaerthur` coût.
- **Voler** : `nythalar` se déplacer dans les airs ; `vaervyrar` dérober.
- **Couler** : `vathar` s’écouler ; `thimdhorar` sombrer dans un liquide.
- **Grave** : `thaemhyriv` registre sonore seulement ; aucune extension automatique au danger ou au sérieux.
- **Temps** : `thir` temps ; `raelthir` climat ; `saunrael` météo.
- **Mémoire** : `nael` mémoire mentale ; `naellym` mémoire vive informatique ; `naelkorun` stockage.
- **Voix / son / musique** : `thaem`, `thaemvath`, `lyrmael` ; ces noms ne sont pas synonymes.
- **Consentement** : `thaevlyren` ; la confiance `dhael` et l’amour `mael` n’en tiennent pas lieu.
- **Chant / action de chanter** : `thael` morceau ; `thaereth` processus. Un résultat n’est pas une nominalisation d’action par défaut.
