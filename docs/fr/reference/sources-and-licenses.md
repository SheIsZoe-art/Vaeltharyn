# Sources et licences

Les créations originales Vaeltharyn relèvent de la notice [LICENSE.md](../../../LICENSE.md). Le catalogue [references.json](../../../data/provenance/references.json) résout les codes d’attribution des fiches.

Les définitions françaises issues des contributeurs du Wiktionnaire, via Kaikki / Wiktextract, conservent leurs attributions et les licences annoncées par cette source. Leurs URL et numéros de sens sont conservés par entrée. Les traductions anglaises n’effacent pas ces références. Le JSONL `data/provenance/definitions-sourcees.jsonl` conserve le texte français utilisé.

- [Données et licences de l’édition française](https://kaikki.org/frwiktionary/).
- [Conditions de réutilisation Wiktionary](https://en.wiktionary.org/wiki/Wiktionary:Copyrights).
- [Licence CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

Les références lexicales et techniques complètent les distinctions de sens ; elles ne valident pas automatiquement les formes proposées en Vaeltharyn. Les statuts de chaque fiche restent applicables. Conserver les crédits et références dans les exports.
