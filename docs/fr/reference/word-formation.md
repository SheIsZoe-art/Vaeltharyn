# Formation des mots

## Principe

Une racine est un matériau lexical inventé ; une forme dérivée est construite par une règle déclarée. On n'invente pas une nouvelle traduction d'un mot déjà canonique pour améliorer une rime. Le vocabulaire poétique garde des sens stables.

## Dérivation

| Base | Opération | Résultat | Sens |
|---|---|---|---|
| radical verbal | + eth | thaereth | action de chanter |
| radical verbal | + or | thaeror | personne qui chante |
| radical verbal | + el | thaerel | instrument destiné au chant |
| nom | + va | saelva | relatif à l'âme |
| adjectif | + eth | naeveth | profondeur |
| adjectif | + is | naevis | profondément |
| nom | + il | saelil | petite âme, valeur diminutive |
| nom | + aun | saelaun | grande âme, valeur augmentative |
| nom ou adjectif | préfixe ul- | ulsaev | non beau, laid |
| nom | + ar | saelar | incarner/manifester une âme |
| radical verbal | + av + ar | neravar | faire dormir |

Les formes sont soudées et les voyelles conservées. Le suffixe -or a deux emplois distincts : sur un nom complet, cas datif ; sur un radical verbal, nom d'agent. `thaeror` est un chanteur ; `thaeroror` est « au chanteur ». Une ambiguïté de segmentation peut exister, comme dans les langues naturelles ; le contexte et le dictionnaire la résolvent. Pour la création de nouveaux mots, éviter les collisions inutiles.

Le préfixe ul- exprime la privation ou le contraire lexical régulier, jamais la négation d'une proposition. Pour un contraire culturel ou une nuance complexe, ajouter une racine distincte au dictionnaire. La dérivation nominale en -ar ne crée pas automatiquement une action transitive : elle signifie « manifester X », intransitif sauf entrée explicite. Une entrée verbale déjà enregistrée prime cette dérivation : on ne réinterprète pas `thalar`, vivre, à partir de `thal`, bras.

## Composition

Deux noms se combinent dans l'ordre **déterminant + noyau** : `sael-aelun`, lumière de l'âme ; `naur-thael`, chant du feu. Le trait d'union est obligatoire pour distinguer composition et racine simple. Seul le dernier élément prend nombre et cas : `sael-aeluniath`, dans les lumières de l'âme.

Le composé ne remplace pas toutes les possessions : `aelun saelen` décrit une lumière appartenant à une âme ; `sael-aelun` désigne une catégorie de lumière. Un adjectif + nom composé garde l'adjectif devant seulement dans un composé lexical enregistré ; sinon l'adjectif suit le nom selon la règle normale.

Termes possibles, transparents et non comptés comme racines indépendantes :

- `sael-aelun` : lumière de l'âme.
- `naur-thael` : chant du feu.
- `lym-vareth` : chemin de lune.
- `syr-nael` : mémoire des étoiles.
- `dhor-aelun` : lumière des profondeurs souterraines.
- `vael-thael` : chant du désir, de la volonté.

## Noms propres et emprunts

Les noms propres restent reconnaissables. Un trait d’union sépare leurs suffixes : `⟨nom propre⟩-en` indique le possesseur, `⟨nom propre⟩-or` le destinataire. Les chevrons désignent un emplacement, pas une graphie de la langue. Un nom ne se traduit pas par une étymologie inventée après coup. Les noms propres n'ont pas à respecter l'alphabet de la langue.

Pour les technologies modernes, former un composé descriptif quand il est clair ; sinon enregistrer un emprunt adapté et le marquer comme tel. Vérifier la définition, la catégorie et la valence de chaque terme spécialisé.

## Ajouter une entrée

1. Définir le sens exact et la catégorie.
2. Chercher une entrée existante dans les deux index.
3. Préférer une dérivation transparente si elle convient.
4. Vérifier graphie, sonorité, homonymes, pluriel et conjugaison.
5. Ajouter un exemple traduisible et mettre à jour les deux dictionnaires.
6. Vérifier les règles dans [le référentiel](canon-and-controls.md) et exécuter les tests.
